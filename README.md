# 杭之的个人网站

我是杭之，07 后的大学新生。从小项目开始，做出别人用得上的东西，记录实际的尝试，也认识愿意一起做事的伙伴。

这是 2026 年 10 月 25 日开始的个人网站初稿，目前进行到第 003 版。布局和经历文案仍在共同打磨，尚非最终版本。

## 本地预览

无需安装依赖，在项目目录运行：

```sh
python3 -m http.server 4173
```

打开 http://localhost:4173 。也可以直接打开 `index.html`。

## 内容方向

网站同时呈现个人想法、项目与真实生活，让访客从具体行动中认识本人。当前表达见 [内容底稿](CONTENT.md)，后续随真实经历与本人想法继续调整。

## 栏目

首页保留自我介绍与栏目入口。About 介绍本人，Writing 整理文字，Build 展示项目，Life 记录生活，Contact 提供联系入口。全部为独立的静态 HTML 页面。

## 创建历程

- [制作日志](BUILDLOG.md)：每次有意义的修改，记录改了什么、为什么改、检查结果。
- [提交记录](https://github.com/wwh837984-code/hang/commits/main/)：保留对应的代码版本。

后续修改先在本地预览和检查，再以一次清楚的提交同步到 GitHub。网站托管尚未连接，推送代码暂时不会发布在线网站。

## 实现

原生 HTML、CSS、JavaScript；无构建步骤、后端或密钥。保留浏览器自然滚动，支持减少动态效果偏好。头像由本人提供。私人笔记、聊天导出与客户素材不在此仓库。

本仓库公开用于记录创作过程，尚未授予通用开源许可；头像与个人内容请勿直接用于他人的身份展示。
